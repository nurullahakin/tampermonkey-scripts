# Screenshots

← [Back to README](README.md)

These were taken on the demo [issue #4](https://github.com/nurullahakin/tampermonkey-scripts/issues/4) and [PR #5](https://github.com/nurullahakin/tampermonkey-scripts/pull/5).

## Issue Progress Bar

Task badge (`done / not done / total`) and progress bar next to the issue state.

![Issue Progress Bar](screenshots/GitHub%20-%20Issue%20Progress%20Bar.png)

## Scroll Boxes

Content between `--- scroll-box ---` markers, shown in a scrollable box.

![Scroll Boxes](screenshots/GitHub%20-%20Scroll%20Boxes.png)

## PR Image Viewer

Lightbox with a thumbnail strip, opened by clicking an image in the PR description.

![PR Image Viewer](screenshots/GitHub%20-%20PR%20Image%20Viewer.png)

## Pretty Commit Messages and Mark Clicked Commits

Commit messages split into type, scope and description chips. Commits that have already been opened are dimmed (the first two here). The last commit has no type prefix, so it is left as is.

![Pretty Commit Messages and Mark Clicked Commits](screenshots/GitHub%20-%20Pretty%20Commit%20Messages%20%26%20Mark%20Clicked%20Commits.png)

## Pretty PR Files

Each changed file shown as a separate card, with more space between them.

![Pretty PR Files](screenshots/GitHub%20-%20Pretty%20PR%20Files.png)

## PR Commits Sidebar

The commit list stays open on the left of the PR changes page, with the current commit highlighted.

![PR Commits Sidebar](screenshots/GitHub%20-%20PR%20Commits%20Sidebar.png)
